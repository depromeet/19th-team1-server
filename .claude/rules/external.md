# 외부 연동 규칙

- 외부 응답 DTO는 이 패키지 밖으로 내보내지 않는다. 도메인 값으로 바꿔 돌려준다.
- 연결·응답 타임아웃을 지정한다.
- 외부 오류는 내부 예외로 바꾼다. 호출 한도 초과는 다른 오류와 구분해 재시도 판단에 쓸 수 있게 한다.
- LLM 호출은 사용량 상한 검사를 거친다.
- LLM에 보낸 내용, 받은 응답 원문, 사용자가 저장한 내용은 로그에 남기지 않는다. 저장물·작업 번호만 남긴다.
- 키는 환경변수로만 받는다.
