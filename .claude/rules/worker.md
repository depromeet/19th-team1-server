# 워커 규칙

- 작업 큐 수신은 `job/`, 예약 작업은 `schedule/`에 둔다.
- 작업 큐는 `core`의 `JobQueue`로만 다룬다. SQS 클라이언트나 리스너 어노테이션(`@SqsListener`)을 쓰지 않는다.
- 처리 작업의 상태 전이는 현재 상태를 조건으로 건 UPDATE로 하고, 갱신된 행이 없으면 그 동작을 하지 않는다. 재시도할 수 있는 실패면 메시지를 지우지 않아 SQS가 다시 보내게 한다.
- 워커와 스케줄러는 서비스를 호출하기만 한다. 재시도 판단, 상태 변경 같은 로직은 서비스와 도메인 모델에 둔다.
- 작업 실패는 시도 횟수와 마지막 실패 사유를 기록하고, 시도 횟수가 상한을 넘거나 재시도해도 소용없는 실패면 `FAILED`로 끝낸다.
- 워커와 스케줄러는 설정 플래그(`WORKER_ENABLED`, `SCHEDULER_ENABLED`)로 켜고 끌 수 있게 한다.
