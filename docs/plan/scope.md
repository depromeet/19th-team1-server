# 프리런칭 범위

12/12 프리런칭에서 서버가 만드는 것이다. 기능의 원본은 디자인 파트의 기능명세서(노션)이고, 이 문서는 그중 서버가 맡는 부분과 서버만의 범위를 적는다. 스토리와 순서는 [roadmap.md](roadmap.md)에 있다.

- **포함**: 프리런칭에서 서버가 만든다.
- **서버 없음**: 화면에서만 처리한다.
- **미정**: 팀 결정을 기다린다. "결정 대기" 표에 무엇을 기다리는지 적는다.

## 기능명세서 밖의 서버 범위

| 범위 | 내용 | 스토리 |
| --- | --- | --- |
| 링크 정규화 | 추적 파라미터 제거, 단축 링크 풀기, 네이버 블로그 URL 변환. 중복 판정은 정규화한 URL로 한다 | E3-1, E4-3 |
| 플랫폼별 수집 | 아래 "플랫폼별 수집 수준" | E4-3 |
| 사용자 메모 | 링크만 저장되는 플랫폼에서 사용자가 남기는 한 줄 메모 | E3-1 |
| 처리 상태 | 저장 요청은 바로 응답하고, 수집·분석은 백그라운드에서 처리한다. 웹은 상태를 폴링한다 | E3-1, E4-5 |
| 카테고리 수정과 재분석 | 카테고리를 바꾸면 상세 정보와 주제어를 다시 뽑는다 | E4-7 |
| 저장물 삭제 | 소프트 딜리트. 사용자에게서는 사라지고 데이터는 보관해 분석에 쓴다 | E3-2 |
| LLM 사용량 상한 | 사용자별·전체 상한 | E4-4 |
| 탈퇴 | 카카오 연결 끊기. 사용자 데이터는 프리런칭 기간 동안 삭제하지 않고 보관해 분석에 쓴다 | E2-2 |
| 푸시 | 채널과 무관한 발송 기반만 만든다. 웹 푸시는 처리하지 않는다 | E7-1, E7-2 |
| 지표 | 방문, 저장물을 어디서 꺼내 보는지, 채팅으로 활용하는지. 지표와 이벤트는 [docs/metrics.md](../metrics.md) | E8-1, E8-2 |

## 플랫폼별 수집 수준

11/19 수집 리서치 결과다. 약관 정책(결정 대기 1)에 따라 바뀔 수 있다.

| 수준 | 플랫폼 | 방법 | 사용자에게 보이는 것 |
| --- | --- | --- | --- |
| 자동 정리 | 유튜브, 블로그·뉴스, 노션 공개 페이지 | 유튜브는 oEmbed와 Data API, 나머지는 OG와 본문 | 제목·요약·카테고리가 채워진 카드 |
| 부분 자동 | X, 핀터레스트 | 공식 oEmbed까지만 | 제목·작성자 카드, 모자라면 메모 요청 |
| 링크 + 메모 | 인스타그램, 쇼핑몰, 카카오맵·선물하기 | URL만 저장하고 분류는 사용자 메모로 | 메모 한 줄 입력 |

- 링크 본문은 저장하지 않는다. 분석에 쓰고 버린다.
- 쇼핑몰(쿠팡, 무신사)은 봇 차단으로 수집이 안 된다.
