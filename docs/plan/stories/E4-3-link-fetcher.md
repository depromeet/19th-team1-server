# E4-3 플랫폼별 링크 수집기

이슈: #61 · 에픽: E4 자동 정리 · 담당: 승환 · 명세: —

## 세부 작업

한 줄이 '실패하는 테스트 하나 → 통과할 만큼만 구현'이다. 테스트는 수집기 인터페이스 `fetch(url)` 하나에서 한다(`HttpLinkContentFetcherTest`). 괄호는 이슈 완료 조건의 순번이다.

- [ ] 1. 유튜브 영상 주소면 oEmbed로 제목·채널·썸네일을 돌려준다 (1)
- [ ] 2. youtu.be·shorts·live·embed·모바일 주소도 같은 영상으로 요청한다 (1)
- [ ] 3. 요청하지 않는 곳은 요청 없이 '요청 안 함' 수집 누락과 최종 주소를 돌려준다. 수집 수준은 `LINK_MEMO`다 (4)
- [ ] 4. 그 외 페이지에서 제목·설명·본문·대표 이미지를 뽑는다 (2)
- [ ] 5. 블로그 호스트(네이버 블로그·티스토리·벨로그·브런치·미디엄)는 `BLOG`, 노션은 `NOTION`으로 정한다. 목록에 없는 블로그는 `OTHER`다. `Platform`을 정리한다 (2, 7)
- [ ] 6. 비공개 노션은 주소의 제목 조각을 제목으로 쓰고 '막힘' 수집 누락을 같이 돌려준다 (2, 6)
- [ ] 7. 네이버 블로그는 모바일 주소로 받는다 (2)
- [ ] 8. 사설망·메타데이터 주소로는 요청하지 않는다. 처음 주소, 리다이렉트된 주소, 다시 해석한 DNS를 모두 본다. 웹 페이지는 Apache HttpClient 5로 받고 연결 직전에 IP를 검사한다 (5)
- [ ] 9. robots.txt가 막으면 받지 않는다. 호스트마다 24시간 기억한다 (5)
- [ ] 10. 단축 주소를 풀고 최종 주소로 플랫폼을 정한다 (3)
- [ ] 11. 수집 누락의 이유와 다시 해 볼 만한지를 돌려준다. 다시 해 볼 만함: 시간 초과, 서버 오류(5xx), 호출 한도(429). 소용없음: 없는 글(404·410, 유튜브 oEmbed 포함), 막힘(401·403), robots 금지, HTML 아님, 위험한 주소, 리다이렉트 5번 초과 (6)
- [ ] 12. 길이를 맞춘다: 제목 500자, 설명 2,000자, 본문 6,000자, 2,048자 넘는 이미지 주소는 버린다. 응답은 앞 3MB까지만 읽고 진행한다 (2)
- [ ] 13. 수집기를 빈으로 등록하고 설정 기본값을 둔다. 봇 이름은 임시 기본값으로 둔다 (1~6)
- [ ] 14. architecture.md를 고친다: 7절 플랫폼 값 목록, 8절 경계 표(누락은 결과 값, 카테고리는 정하지 않음), 10절 결정 네 줄(카테고리를 정하지 않음, 누락은 결과 값, 유튜브는 oEmbed만, robots.txt를 지키고 요청하지 않는 곳은 요청하지 않음), 11절 10번 삭제. scope.md의 유튜브 줄을 고친다 (8)

## 참고

- 규칙: `.claude/rules/architecture.md`, `.claude/rules/external.md`(타임아웃, 오류 변환, 로그), `.claude/rules/testing.md`(가짜 HTTP 서버, 고정 시계)
- 문서: `docs/architecture.md` 8절 경계 인터페이스(`LinkContentFetcher`)·7절 `saved_item.platform`, `docs/plan/scope.md` "플랫폼별 수집 수준"·결정 대기 1
- 결정(11/22 grill)
  - 수집 결과: 최종 주소, 플랫폼, 수집 수준, 제목, 작성자, 설명, 본문(저장하지 않음), 대표 이미지 주소, 수집 누락
  - 수집기는 `originalUrl`을 받는다. 저장물 주소는 바꾸지 않는다
  - 수집기는 카테고리를 정하지 않는다. 주소 카테고리는 분석(E4-6)이 정한다
  - 수집 누락은 예외가 아니라 결과 값이다. 이유 enum과 다시 해 볼 만한지만 돌려주고, `fail_code` 문자열과 작업 실패 여부는 E4-6이 정한다
  - 수집 수준은 결과가 아니라 경로로 정한다
  - 유튜브는 oEmbed만 쓴다(JDK HttpClient 그대로)
  - `Platform`은 YOUTUBE·BLOG·NOTION·OTHER(11/21). 테스트 위치는 `fetch(url)` 하나
